# Product Catalog MVC - Practical 6

ASP.NET MVC 5 (.NET Framework) sample based on the supplied Practical 6 PDF.

## Features
- Product catalog listing
- Product details page
- MVC model, controller, Razor views, and routing
- Sample products: Laptop, Mobile, Headphones

## Open and run
1. In Visual Studio, create **ASP.NET Web Application (.NET Framework)**.
2. Select the **MVC** template and name the project `ProductCatalogMVC`.
3. Copy/merge the source files in this folder into the generated project.
4. Keep the Visual Studio-generated `.sln`, `.csproj`, `Web.config`, `packages.config`, `App_Start/BundleConfig.cs`, and `App_Start/FilterConfig.cs` files. These contain version-specific build/configuration details.
5. Build the solution and press `Ctrl+F5`.

Default route: `/Product/Index`

## GitHub
Create a repository on GitHub, then from the project root run:
```bash
git init
git add .
git commit -m "Add Product Catalog MVC Practical 6"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

Replace the URL with your repository URL. This folder contains the application source files; Visual Studio-generated solution/configuration files must be added from the MVC template for a fully buildable .NET Framework project.
